solyra-app — Universal Linux App Installer for Solyra OS

Commands:
  solyra-app search <query>           Search Flathub + Arch repositories
  solyra-app install <app-or-id>      Install any Flatpak app from Flathub
  solyra-app pacman <pkg...>          Install native Arch packages
  solyra-app remove <app-id>          Uninstall a Flatpak app
  solyra-app list                     List installed Flatpak apps
  solyra-app box [ubuntu|arch|fedora] Enter a Distrobox for apt/pacman/dnf apps
                                      (use `distrobox-export --app <name>` to add to Dock)
  solyra-app appimage <file.AppImage> Install & register an AppImage in Spotlight/Dock
