# Glyphs

UI glyphs from **Solar** (Linear style) by [480 Design](https://www.figma.com/community/file/1166831539721848736),
licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). This is the
icon set zeron uses for its interface. The PNGs are 48 px alpha masks baked
from the `@iconify-json/solar` package by `bake_solar.py`; the panel tints them
at draw time. Edit the `GLYPHS` table in the script to add one.
